Install

Three steps. That's it.

No installer: Fuzzie is one small file that keeps itself up to date.

Get it

Download Fuzzie.exe and put it anywhere you like.

Run it

Windows may warn you because the app is new: click More info, then Run anyway.

Say hi

Fuzzie appears at the top of your screen, starts with Windows and updates itself.

Questions

Good to know.

Is it free?

Yes, and the code is open on GitHub.

Does it slow my PC down?

No. It's written in Rust, uses a few MB of memory and almost no CPU while idle. The notch and Desktop Fuzzie only draw when something moves.

What is Desktop Fuzzie?

An optional fluffy buddy (Fox, Cat, Bunny, Shiba or Red Panda) that sits on your taskbar and taps along as you type and click. Turn it on in Settings → Desktop Fuzzie.

What do my friends see?

Your name, your look, whether you're online and the song you're playing. You can stop sharing your music, or go offline, in Settings.

Do I need an account?

No. Fuzzie makes a friend code for you on first start. There's no email or password.

Why does Windows warn me?

The exe isn't signed yet, so SmartScreen doesn't know it. Click More info, then Run anyway. You can read every line of the source on GitHub.

How do I remove it?

Settings → About → Uninstall Fuzzie. It removes your data, your friend code and the app itself.
